# Laptop Sales Data Analysis (Power BI)

## Overview

This project analyzes laptop sales data using Power BI. The dashboard provides insights into laptop brands, types, operating systems, storage configurations, RAM, and pricing trends.

## Features

* Distribution of laptops by type (Notebook, Gaming, Ultrabook, etc.)
* Company-wise sales analysis
* Operating system comparison
* Storage analysis (SSD and HDD)
* RAM vs Price relationship
* Brand and product category performance

## Dashboard Insights

* Notebooks are the most common laptop type.
* Windows is the dominant operating system.
* Higher RAM configurations generally have higher average prices.
* Major brands such as Dell, Lenovo, HP, Asus, and Acer contribute significantly to sales.
* SSD and HDD capacities impact laptop pricing.

## Tools Used

* **Power BI Desktop**
* Data Visualization
* Data Analysis

## Files

* `project.pbix` – Power BI project file
* `project0.pdf` – Exported dashboard report

## How to Use

1. Download the `.pbix` file.
2. Open it in Power BI Desktop.
3. Explore the interactive dashboards and visualizations.

## Project Objective

To analyze laptop sales data and identify trends related to brands, specifications, operating systems, and pricing using Power BI.
